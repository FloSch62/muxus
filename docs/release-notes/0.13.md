# Release 0.13

:material-calendar: 24 October 2026 · [Full changelog](https://github.com/FloSch62/muxus/compare/v0.12.1...v0.13.0)

Release 0.13 makes everyday work quicker. Settings can be searched, the file browser selects
several files to download or delete together, and a tab can close by itself when its shell
exits. On macOS, ++cmd+left++ and ++cmd+right++ jump to the start and end of the line, and
++option+left++ and ++option+right++ jump by word in split panes too.

## Searching settings

Finding a setting meant knowing which section holds it. **Search settings**, above the
section list, finds a setting by its name or by what it is about, such as `dark mode`,
`keepalive`, `ctrl+d` or `osc52`. Results list as you type, each with its section and
heading, and choosing one opens the section, scrolled to the setting and outlined for a
moment. ++ctrl+f++ (++cmd+f++ on macOS) moves to the search field from anywhere in Settings;
in a narrow window it sits above the section picker.

See [settings](../guide/settings.md).

## Selecting several files

The file browser now selects rows as a file manager does: ++ctrl++ + click (++cmd++ + click
on macOS) adds a row or takes it out again, ++shift++ + click selects a range, ++ctrl+a++
(++cmd+a++) selects the whole folder, and ++esc++ or a click below the rows clears the
selection. The toolbar shows how many rows are selected.

:material-download: downloads every selected file. The desktop app and Chromium browsers ask
once for a folder and save them all there; a file of the same name already in the folder is
kept and the new one is numbered, as in `report (1).txt`. Firefox and Safari save the files
to their downloads folder. The row menu of a selected row downloads or deletes the whole
selection, ++delete++ (++cmd+backspace++ on macOS) deletes it too, and deleting asks once for
all of them.

See [selecting several files](../guide/files.md#selecting-several-files).

## Closing a tab when its shell exits

Leaving a shell with `exit`, `logout` or ++ctrl+d++ kept the tab open with *Press any key to
reconnect*. With **Close the tab when its shell exits**, a new setting under **Settings →
Behavior** that is off by default, a local, SSH or Telnet tab closes instead when its shell
exits by itself with status 0. A shell that exits with another status, a failed or lost
connection, a serial console and a pinned tab keep the tab with the usual prompt, and a tab
with unsaved remote files asks first. Backups keep the setting.

See [behavior settings](../guide/settings.md#behavior).

## Line and word jumps on macOS

++cmd+left++ and ++cmd+right++ did nothing at a prompt. They now jump to the start and end of
the line, as in VS Code and Ghostty, by sending ++ctrl+a++ and ++ctrl+e++, which bash, zsh,
fish and the CLIs of most network devices understand. They are the **Jump to line start**
and **Jump to line end** commands in the keyboard sheet, where they can be rebound, or
cleared to pass the keys through unchanged. On Windows and Linux, where ++home++ and ++end++
already do this, the commands have no shortcut until one is recorded.

++option+left++ and ++option+right++ also moved focus between panes, so with two panes side
by side a word jump towards the other pane focused it instead. On macOS, focus now moves with
++cmd+option++ and an arrow, as in iTerm2, and ++option+left++ and ++option+right++ always
jump by word. Windows and Linux keep ++alt++ and an arrow.

See [protocols](../guide/terminal.md#protocols) and
[tabs and panes](../guide/tabs-and-panes.md).

## Smaller improvements and fixes

- A file dragged out of the file browser more than two minutes after its folder was listed
  downloads again, instead of failing and, on macOS, leaving an empty file in Finder.
- On macOS, **Muxus → About Muxus** opens **Settings → About**, with links to GitHub, the
  docs, the release notes and the issue tracker, instead of the bare system About panel.

This release also moves to Electron 45 and refreshes Fastify, TanStack Query, React,
zustand and development tools.

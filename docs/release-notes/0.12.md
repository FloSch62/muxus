# Release 0.12

:material-calendar: 15 October 2026 · [Full changelog](https://github.com/FloSch62/muxus/compare/v0.11.1...v0.12.0)

Release 0.12 continues the work on device consoles. Pastes can wait for the device's prompt
after each line and stop at the first line it rejects, a saved configuration can be typed in
from a file, and hosts can choose what Backspace and Enter send, turn on local echo and keep
idle lines open. Two texts, such as `show running-config` before and after a change, can be
compared side by side, pastes flag invisible and look-alike characters, command buttons run
from their own shortcuts, and the SecureCRT import brings Telnet sessions and button bars.

## Pastes that wait for the prompt

A fixed line delay is either longer than most lines need or shorter than the slowest one.
A host can now have pastes wait for the device's prompt after each line instead: the next
line goes out as soon as the prompt is back, so a long configuration goes in as fast as the
device answers. Switch on **Wait for the prompt after each line** under **Paste pacing** in
the host's **Terminal appearance**.

The paste also stops at the first line the device rejects, so the rest of a configuration
never lands in the wrong context. The terminal and the session history quote the rejected
line and the device's answer, such as `% Invalid input detected`. The prompt pattern, the
error pattern and the timeout default to IOS-style values and can be set per host; without a
prompt within the timeout, the line falls back to the line delay. With multi-execution, each
mirrored session waits for its own prompt.

See [waiting for the prompt](../guide/terminal.md#waiting-for-the-prompt).

## Sending a text file

**Send text file…** types a local text file into an SSH, Telnet or serial session, such as a
saved configuration for a console. It goes the way a command button does: at the host's paste
pace, waiting for the prompt when the host does, after any paste still running, and into
every mirrored session with multi-execution. It is in the terminal-actions menu, the tab's
right-click menu and the quick launcher, and a shortcut can be recorded for it. Binary files
and files over 1 MB are refused before anything is typed.

See [sending a text file](../guide/terminal.md#sending-a-text-file).

## Keys and echo

Some consoles expect Backspace as ^H or Enter as CR LF or LF, do not echo what they receive,
or end output lines with LF alone. SSH, Telnet and serial hosts now have **Keyboard and
echo** under **Terminal appearance**: what **Backspace** and **Enter** send, an implicit CR
for every received LF, and local echo. The Enter key also applies to pastes, command
buttons, secrets, login sequences and anti-idle, and SSH sessions announce a ^H Backspace to
the server as their erase character. With multi-execution, each session sends the keys its
own host asks for.

See [keys and echo](../guide/terminal.md#keys-and-echo).

## Keeping idle sessions open

Devices and console servers close a VTY or console line after a spell without input, and SSH
keepalives do not count as input there. A host can now have Muxus type a text into its
sessions once they have been idle for 10 to 3600 seconds, with Enter only when you tick it.
Any input starts the wait over, the wait is held while a paced paste or login sequence runs,
and on Telnet and serial hosts it starts only after the first input, so a session left at a
login prompt never gets the text as a username. Multi-execution never mirrors it.

See [keeping idle sessions open](../guide/terminal.md#keeping-idle-sessions-open).

## Comparing texts

**Compare with…** opens two texts side by side or inline: a terminal's output or selection,
a session history record, or a local or SFTP file. It is in the session history dialog, the
terminal's context menu and the file browser. A comparison can ignore whitespace and leading
timestamps, so a router's configuration or routes from before and after a change line up,
and **Export diff** saves it as a unified diff. Soft-wrapped terminal lines are compared
whole, and **Copy all output** and **Export as text** now join them too.

See [comparing](../guide/session-history.md#comparing).

## Invisible and look-alike characters in pastes

Text copied from Word, Teams or a wiki can carry no-break spaces, zero-width characters,
smart quotes, dashes, or Cyrillic and Greek letters that look like Latin ones, and a device
then rejects the line or stores a different value. The paste preview lists these characters
with their line and column, and **Replace with ASCII** fixes them before anything is sent. A
single-line paste that contains one opens the preview too, as long as **Confirm pastes with
look-alike characters** is on in **Settings → Terminal**, as it is by default. Words written
entirely in Cyrillic or Greek are left alone.

See [invisible and look-alike characters](../guide/terminal.md#invisible-and-look-alike-characters).

## Command button shortcuts

A command button can have a key combination of its own that runs it in the focused session,
as a click does. Record it from the keyboard icon in the command-button manager or in the
keyboard sheet; a combination that a Muxus command, another button or the shell already uses
is refused with the reason. The shortcut shows in the button's tooltip and the
++ctrl+space++ menu, and backups keep it.

Buttons are now also typed at the host's paste pace, so a multi-line command reaches a slow
console intact. A button pressed during a paced paste waits for it to finish, and
multi-execution mirrors buttons as it mirrors typed input.

See [button shortcuts](../guide/commands.md#button-shortcuts).

## SecureCRT Telnet sessions and button bars

The SecureCRT import now keeps Telnet sessions, with their host and port, instead of
skipping them, and reads the export's button bars. Each bar becomes a command button group,
**Send String** buttons become the text they type, and a host whose session used a bar shows
that group in the command bar. SecureCRT's own **Default** bar fills Muxus's **Default**
group while it holds no buttons of yours. Importing a bar again keeps or replaces its
commands as a whole, and the review lists what could not be converted.

See [import from SecureCRT](../guide/hosts.md#import-from-securecrt) and
[button bars](../guide/hosts.md#button-bars).

## Smaller improvements and fixes

- The status bar no longer drops SSH sessions to older Nokia SR OS routers right after the
  prompt appears. Host statistics are only read from servers that already ran a command
  while the session opened, so routers, console servers and hosts with shell integration
  turned off are never asked.
- Duplicating or splitting a tab to a router that refuses commands no longer fails with
  *Channel open failure* after a few tabs.
- Saving an SSH host in the editor no longer adds `IdentitiesOnly yes` when it has an
  `IdentityFile` and only an unrelated setting changed, so agent keys keep being offered.
  `IdentitiesOnly true` is now read as `yes`, as OpenSSH reads it.
- On macOS, ++option+left++ and ++option+right++ jump by word at the shell and on network
  device CLIs.
- Box-drawing and block-character art, such as frames and logos, renders without gaps and
  squashed glyphs, with or without GPU rendering.
- The settings window opens centered over the window it was opened from, at the size it was
  last left.
- **Add gNMI host for it…** and **Add NETCONF host for it…** on an SSH host that is reached
  through a jump host use that jump host as the new host's SSH gateway.
- A paste sent right after cancelling another one is no longer dropped.

This release also refreshes Electron, xterm.js, Fastify, zod, TanStack Query and development
tools.

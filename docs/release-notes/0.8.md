# Release 0.8

:material-calendar: Upcoming · [Changes since 0.7](https://github.com/FloSch62/muxus/compare/v0.7.0...main)

Release 0.8 brings remote desktops and graphical SSH applications into Muxus, adds regular
expressions and network-device profiles to terminal highlighting, and makes session history
easier to read with optional per-line timestamps.

## Remote desktops beside your terminals

RDP and VNC hosts now share the host list, folders, split panes and workspaces with your
terminal sessions. Both clients are built in, with optional SSH gateways for reaching
desktops through an existing SSH connection. Desktop tabs support resizing, text clipboard
sharing, reconnecting and saving successful logins in the encrypted password vault.

RDP supports NLA and TLS connections, with certificate trust prompts for unrecognized
servers. VNC supports several authentication methods, including RSA-AES with server-key
verification. Remote desktops stay out of mirrored terminal input.

See [remote desktop](../guide/remote-desktop.md) for setup, supported authentication methods
and current limitations.

## Graphical applications over SSH

X11 forwarding lets graphical programs launched in an SSH session open windows locally.
The Windows app bundles VcXsrv and gives each SSH connection its own display, started on
demand. Windows clipboard sharing is off by default and can be enabled in Settings.

On macOS, install XQuartz and enable X11 forwarding in Settings. Linux uses your existing
X11 or XWayland display. Forwarding is opt-in per host on macOS and Linux; Windows enables
it by default with the bundled server. Global settings and host overrides control which
connections request it.

See [graphical apps](../guide/x11.md) for platform setup and the differences between a
dedicated Windows display and forwarding into your desktop's existing X server.

## More flexible terminal highlighting

Highlight rules can now use regular expressions as well as literal keywords. Built-in
Nokia SR OS and SR Linux profiles provide reusable rules for network-device output, and
profiles can be assigned to hosts and imported or exported as JSON.

Pattern matching runs in a worker so expensive expressions cannot stall the terminal.
See [keyword highlighting](../guide/terminal.md#keyword-highlighting).

## Timestamps in session history

**Show timestamps (UTC)** adds an ISO 8601 timestamp with milliseconds to each transcript
line, including copied transcripts and clean-log downloads. New recordings track when
Muxus received the last change to a line; older recordings use approximate event times
and are labeled accordingly. The toggle starts off, and raw logs and HTML replay retain
their existing formats.

See [session history](../guide/session-history.md) for recording and export options.

## Desktop and maintenance updates

Muxus has a new app icon and an About page in Settings. Release tooling adds macOS
Developer ID signing and notarization, plus Microsoft Store packaging and submission
support. Store availability depends on certification; see the
[desktop installation guide](../install/desktop.md) for distribution details.

This release also refreshes Electron, the native credential-store library, terminal
packages and development tools. React remains on 19.2 to keep initial loading within
the existing bundle budget.

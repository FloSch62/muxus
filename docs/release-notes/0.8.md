# Release 0.8

:material-calendar: 2 October 2026 · [Full changelog](https://github.com/FloSch62/muxus/compare/v0.7.0...v0.8.1)

Release 0.8 brings remote desktops and graphical SSH applications into Muxus, adds regular
expressions and network-device profiles to terminal highlighting, and makes session history
easier to read with optional per-line timestamps. It also marks a milestone for desktop
distribution: signed and notarized macOS releases and a Microsoft Store release for Windows.

## Signed for macOS, now in the Microsoft Store

Starting with 0.8, the macOS app is signed with an Apple Developer ID and notarized by
Apple. The universal download supports both Intel and Apple Silicon Macs.

Muxus is also available in the
**[Microsoft Store](https://apps.microsoft.com/detail/9PCGP101LFPL)**, giving Windows
users a new way to install it and receive updates through the Store. The GitHub downloads
remain available.

See the [desktop installation guide](../install/desktop.md) for download and installation
details.

## Updates from inside Muxus

From 0.8 on, Muxus updates itself. When a new version is out, a notice offers to download
it, and **Restart to update** installs it once you are ready. Nothing downloads or
installs without your choice, and quitting normally never installs an update. This works
for the Windows installers (x64 and ARM64), macOS and the Linux AppImage; the Microsoft
Store version offers **Update now** through the Store, and `.deb` installs keep updating
through the package manager. 0.8 itself has to be downloaded once by hand. See
[Updating Muxus](../install/desktop.md#updating-muxus).

## Remote desktops beside your terminals

RDP and VNC hosts now share the host list, folders, split panes and workspaces with your
terminal sessions. Both clients are built in, with optional SSH gateways for reaching
desktops through an existing SSH connection. Desktop tabs support resizing, text clipboard
sharing, reconnecting and saving successful logins in the encrypted password vault.

RDP supports NLA and TLS connections, with certificate trust prompts for unrecognized
servers. VNC supports several authentication methods, including RSA-AES with server-key
verification. Remote desktops stay out of mirrored terminal input.

See [remote desktop](../guide/remote-desktop.md) for setup, supported authentication methods
and current limitations.

## Graphical applications over SSH

X11 forwarding lets graphical programs launched in an SSH session open windows locally.
The Windows app bundles VcXsrv and gives each SSH connection its own display, started on
demand. Windows clipboard sharing is off by default and can be enabled in Settings.

On macOS, install XQuartz and enable X11 forwarding in Settings. Linux uses your existing
X11 or XWayland display. Forwarding is opt-in per host on macOS and Linux; Windows enables
it by default with the bundled server. Global settings and host overrides control which
connections request it.

See [graphical apps](../guide/x11.md) for platform setup and the differences between a
dedicated Windows display and forwarding into your desktop's existing X server.

## More flexible terminal highlighting

Highlight rules can now use regular expressions as well as literal keywords. Built-in
Nokia SR OS and SR Linux profiles provide reusable rules for network-device output, and
profiles can be assigned to hosts and imported or exported as JSON.

Pattern matching runs in a worker so expensive expressions cannot stall the terminal.
See [keyword highlighting](../guide/terminal.md#keyword-highlighting).

## Timestamps in session history

**Show timestamps (UTC)** adds an ISO 8601 timestamp with milliseconds to each transcript
line, including copied transcripts and clean-log downloads. New recordings track when
Muxus received the last change to a line; older recordings use approximate event times
and are labeled accordingly. The toggle starts off, and raw logs and HTML replay retain
their existing formats.

See [session history](../guide/session-history.md) for recording and export options.

## Desktop and maintenance updates

Muxus has a new app icon and an About page in Settings.

This release also refreshes Electron, the native credential-store library, terminal
packages and development tools. React remains on 19.2 to keep initial loading within
the existing bundle budget.

## Patches

### 0.8.2

:material-calendar: 4 October 2026 · [Changes](https://github.com/FloSch62/muxus/compare/v0.8.1...v0.8.2)

- Terminal sessions can be written to a plain-text log file while they run, independent of
  session history: **Log session to file…** in the terminal-actions menu starts one, and
  **Write log files** in a logging policy starts one for every session. See
  [log files](../guide/session-history.md#log-files).
- **Settings → Appearance → Custom color schemes** holds terminal colour schemes of your
  own, copied from any scheme or imported from Windows Terminal and iTerm2 files. See
  [custom colour schemes](../guide/terminal.md#custom-colour-schemes).
- The **Terminal** entry at the start of a session's file strip, or ++ctrl+grave++, brings
  the terminal back in front of open files, which keep their unsaved changes. See
  [the file editor](../guide/editor.md).
- `muxus --connect [user@]host[:port]` opens an SSH tab to any host, including one that is
  not in Muxus or `~/.ssh/config`, for tools with their own device lists. See
  [ad-hoc SSH connections](../reference/cli.md#ad-hoc-ssh-connections).
- The desktop app connects to Windows RDP hosts that use the self-signed certificate
  Windows creates, instead of failing with "Muxus could not connect to the remote
  computer." See [Windows' own certificate](../reference/security.md#remote-desktops).
- Text fields show exactly what was typed: font ligatures no longer draw `<=`, `=>` or
  `->` as a single symbol, so regex highlighting rules read back correctly.
- Undoing an edit in **Settings → Session logging** clears its **Unsaved changes** marker,
  and closing Settings no longer asks to discard changes that were reverted.

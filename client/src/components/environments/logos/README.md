# Environment logos

Shown beside the tools Muxus finds on a host. Each mark belongs to its project.

| File | Source |
| --- | --- |
| `docker.svg`, `kubernetes.svg`, `proxmox.svg` | [Simple Icons](https://simpleicons.org/) 15.0.0 (CC0), filled with the brand color |
| `podman.svg` | `logo/podman-logo-source.svg` of [containers/podman](https://github.com/containers/podman), cropped to the seal without the wordmark |
| `containerlab.svg`, `containerlab-dark.svg` | The Containerlab flask mark, `site/images/favicon.svg` of [srl-labs/containerlab](https://github.com/srl-labs/containerlab); its dark-scheme outline is split into a file of its own so the app's theme picks it |
| `libvirt.svg` | `docs/logos/logo-square.svg` of [libvirt](https://gitlab.com/libvirt/libvirt), editor metadata removed |
